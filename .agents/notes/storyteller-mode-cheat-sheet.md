# Storyteller Mode Cheat Sheet

Quick reference for contributors documenting game lore.

## Key Responsibilities
- Read preflight docs before work.
- Review lore planning docs in `.agents/lore/planning/` before writing notes.
- Capture clarifications and developer responses in `.agents/lore/notes/`.
- Expand existing lore direction without inventing unsupported concepts.
- Keep this cheat sheet updated with durable references.
